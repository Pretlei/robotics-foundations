# When does RL make sense?

- best for learning how to act in a dynamic system where you don’t know the correct actions ahead of time
- for problems where actions influence future states
- when the correct policy is unknown
- use when its easier to score behaviour than when to specify how to do it
- best for uncertain environments

TLDR: when the system is dynamic, optimal behaviour is unknown, trial and error is feasible (maybe even in real life), rewards are easier to define than instructions
